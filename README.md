# Does It Age Verify?

A running list of operating systems and their current status regarding mandatory age verification.

This includes both closed source operating systems (Microsoft Windows, Apple macOS, etc.) and open source operating systems (Linux, *BSD, etc.).

Several jurisdictions have passed, proposed, or withdrawn laws that require operating systems themselves to perform some level of age verification or reporting.

**Last updated:** 2026-06-22
